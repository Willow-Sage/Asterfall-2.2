# Milestone 1 asset gate

No third-party model has been acquired or licensed. Do not mark the visual milestone complete.

Character: properly authored anime GLB with humanoid rig and Idle/Walk/Run clips, or VRM with separately licensed humanoid animations. VRM runtime support is not yet implemented. Obtain source, author, license, redistribution permissions, texture files, skeleton information, scale, and animation names before importing.

Environment: authored Solterran village square with Iberian regional identity, tiled roofs, limestone, textured paving, arcades, fountain, foliage, and collision geometry. Do not use procedural primitive buildings as substitutes.

Suggested authoring route: VRoid Studio for a custom base avatar, followed by authored fantasy clothing and licensed animations; custom Blender village kit. Software availability does not establish rights to downloaded clothing, hair, or animation assets. Review each asset separately.

Asset acceptance: compare front, side, back, close face, and actual runtime wide screenshots against both supplied boards. Record licenses in ASSET_LICENSES.md. Confirm skeleton, foot placement, camera occlusion, performance, and shading before expansion.
